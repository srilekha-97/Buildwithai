# EduAdapt local demo authentication

This version runs authentication locally because the original Lovable/Supabase
credentials are not available.

Run:

    npm install
    npm run dev

Then open the Vite Local URL.

Create an account with an email, name, and password. The account is stored in
the browser's local storage and can be used to sign in again on the same
browser/device.

Google sign-in and Supabase cloud sync remain disabled in this local demo.
